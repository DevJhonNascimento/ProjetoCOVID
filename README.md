# ProjetoCOVID

Repositório acadêmico de experimentos em C++ para Windows. Ele reúne um protótipo de cadastro de pacientes relacionado à COVID-19 e exemplos de instrumentos musicais virtuais no console.

## Conteúdo

- `main.cpp` e `meuPIM.cpp`: versões do protótipo de cadastro de pacientes.
- `projeto.cc` e `teste.cpp`: experimentos de instrumentos musicais virtuais.
- `output/loucura.txt`: dados de exemplo para reprodução musical.

Os programas são protótipos incompletos, usam APIs específicas do Windows e não devem ser usados para armazenar dados reais de saúde. Os executáveis compilados e configurações locais do editor não são mantidos no repositório.
